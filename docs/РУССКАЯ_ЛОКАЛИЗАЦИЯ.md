# Русская локализация проекта

## Цель

Создать русскую версию руководства по эффективной жизни, сохранив исходный принцип проекта:

**рекомендация → затраты → польза → уровень доказательности → источники**

## Правила перевода

- Не переводить механически китайские реалии.
- Адаптировать примеры под русскоязычного читателя.
- Сохранять научные источники, если они являются международными.
- Заменять локальные нормы и законы на актуальные российские аналоги.
- Не добавлять неподтвержденные советы.

## Термины

| Оригинал | Русская версия |
| --- | --- |
| 成本 | Затраты |
| 说人话 | Простыми словами |
| 收益 | Эффект |
| 证据等级 | Уровень доказательности |
| 来源 | Источники |
| 备注 | Примечания |

## Статус и порядок работ

1. Главы 1–31 переведены полностью по списку рекомендаций: 498 пунктов. Открытые вопросы источников и российской адаптации указаны в [аудите](АУДИТ_ЛОКАЛИЗАЦИИ.md).
2. Перевести `docs/`, затем веб-интерфейс и сквозную навигацию.
3. Только после полного перевода — аналитика базы и проектирование Telegram.

## Уточнения к правилам

- Российский аналог вводится только при проверке применимой нормы. В остальных случаях явно обозначать китайскую юрисдикцию и требуемую адаптацию; не заменять юани рублями и названия ведомств механически.
- Сохранять все исходные рекомендации и источники, в том числе отрицательные и спорные результаты. Наблюдательную связь не превращать в гарантию личного эффекта.
- A/B/C — категории исходного автора, не GRADE; сохранять с оговоркой, а не повышать убедительность переводом.
- Источники оформлять кликабельными библиографическими описаниями. Неизвестные сведения помечать, а не восстанавливать догадкой.
- Русские машинные метки имеют вид `<!-- cost-tags: money=0 time=low effort=none benefit=high outcome=health -->`. Значения переданы из оригинала для будущей адаптации фильтров; это не новые оценки экономической эффективности.
- Дата фактической проверки и нерешённые вопросы фиксируются в аудите. Китайские исходники до завершения сверки сохраняются.
