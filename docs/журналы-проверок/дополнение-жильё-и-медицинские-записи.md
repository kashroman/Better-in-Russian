# Журнал: два пункта о жилье и источники медицинских записей

**Историческая проверка автора: 7 сентября 2026.** Тогда книга выросла с 344 до 346 пунктов; пункт 6 главы 24 перевели из C с неполученным источником в A. Это авторские категории, не новая оценка клинической доказательности. Нормы ниже относятся к Китаю.

## Исправление прежнего вывода

Ранее поиск правил найма жилья, посредников недвижимости, предотвращения медицинских споров и ведения медицинских записей в правительственной базе дал пустой результат. В двух журналах это ошибочно превратилось в вывод «документов в базе нет»: [исходная запись о хронических болезнях, уходе и данных](../核实记录/追加-慢病长护险与个人信息权利.md) и [добавление глав 24–25](24-25-медицина-и-дела-после-смерти.md).

Причина по записи автора — параметр `searchfield=title|default`: добавление `default` включало совпадения в тексте плановых документов, вытесняя точные заголовки. После замены на `searchfield=title` сразу нашлись все четыре документа. Прежние выводы об их отсутствии отменены. Это исторический отчёт о поиске, не результат нового обращения к API в рамках перевода.

## 3. Авторские метки

- Специальный счёт сделки вторичного жилья: «деньги, высокий эффект», поскольку сделки измеряются сотнями тысяч/миллионами юаней. Размер возможной сделки не равен доказанной сумме предотвращённого ущерба.
- Жильё за перегородками: «деньги, средний эффект» — переезд, залог, предоплата в сотни–тысячи юаней; пожарный риск упоминался отдельно, без перевода в деньги.
- Медицинские записи: «деньги, средний эффект» сохранено; изменили лишь источник и A вместо C.

Суммы — исходные китайские ориентиры, не российская цена и не текущая гарантированная выплата.
