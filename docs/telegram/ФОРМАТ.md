# Формат темы и подготовка публикации

Формат согласован 19 сентября 2026 года. Аудитория широкая; тематика охватывает всю книгу. Основная единица — одна ситуация читателя и одно осмысленное действие. Несколько рекомендаций могут стать одним постом, если решают одну задачу.

## Карточка темы

| Поле | Что записываем |
| --- | --- |
| ID | Постоянный номер вида 05.01: глава и рекомендация. Для новых тем — NEW-01 и далее. |
| Рубрика | Деньги; работа и внимание; бытовая и цифровая безопасность; здоровье; отношения и семья; права и документы. |
| Ситуация читателя | Конкретный момент, когда пост пригодится. У исходных тем вне плана пока используется объяснение из книги; его нужно уточнить. |
| Заголовок | Понятный вход в тему без неподтверждённых обещаний. |
| Главный тезис | Что читатель должен понять; не больше одного центрального утверждения. |
| Что делать | Действие или короткая последовательность. Если нужен специалист — понятный вопрос к нему. |
| Источники | Прямые ссылки и связь источника с утверждением; книга служит отправной точкой. |
| Ограничения | Для кого вывод не установлен; наблюдение или эксперимент; относительные и абсолютные показатели; условия применения. |
| Россия | Проверенные местные правила либо явное указание, что адаптация ещё не выполнена. |
| Готовность | Исходная тема → отобрана / резерв → проверка → черновик → готово → опубликовано. |
| Место в плане | Неделя, день; календарную дату назначаем после выбора старта. |
| Учёт проверки | Дата, проверенные утверждения, источники и оставшиеся вопросы. |
| Учёт публикации | Финальный текст, дата и ссылка на пост после фактической публикации. |

Уровень A/B/C из книги сохраняется для истории и не заменяет проверку. Он не определяет автоматически готовность или убедительность поста.

## Как выглядит будущий пост

Рабочая структура: заголовок → узнаваемая ситуация → объяснение → действие → важная граница → 1–3 основных источника. Длинный список источников остаётся в карточке. Объём выбираем по содержанию; ориентир для короткого поста — 800–1500 знаков, для разбора — до 2500. Это редакционное предложение, а не техническое ограничение Telegram.

Цифра необязательна. Не нужно вставлять процент ради убедительности, если исследование не поддерживает его перенос на читателя. Разбор исследования и бытовой эксперимент обозначаем прямо; результат личного эксперимента не объявляем доказательством общего эффекта.

## Когда можно поставить «готово»

- Написан полный текст, а не только заголовок и план.
- Каждое проверяемое утверждение опирается на доступный первоисточник; зафиксированы дата и объём проверки.
- Сохранены существенные ограничения. Медицинские действия и российские правовые процедуры проверены отдельно там, где они нужны.
- Нет повторения недавно выпущенного поста с тем же выводом и действием.
- Заголовок, текст и источники согласуются между собой; ссылки открываются.

Авторская идея или рабочий лист могут не требовать исследования для каждого пункта, но их нельзя выдавать за научно доказанный способ получить результат.

## Как поддерживать базу

Карточки Markdown — рабочие документы редактора. JSON — структурированный снимок той же базы на дату создания; после содержательных изменений обновляем и его перед переносом в другую систему. Дату проверки нельзя проставлять массово по дате изменения файла.

Раз в неделю пересматриваем ближайшие две недели: сколько текстов действительно готово, какие проверки задерживаются, какой резерв заменит выпавшую тему. После первых четырёх недель оцениваем интерес по сопоставимым просмотрам, пересылкам, реакциям и вопросам читателей; не сравниваем только сырые просмотры постов разного возраста. Правила доступа к статистике Telegram здесь не предполагаются.

Название канала и постоянные хэштеги пока не утверждены. «Скучная База» может стать рубрикой о полезных привычках, но не навязывается как название всему проекту.
