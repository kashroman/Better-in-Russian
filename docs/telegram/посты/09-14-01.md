# У главной почты должен быть дополнительный барьер

Проверьте почтовый аккаунт, которым пользуетесь для важных регистраций. Что потребуется для входа, если кто-то узнает ваш пароль?

Двухэтапная аутентификация добавляет проверку личности. Конкретные варианты зависят от сервиса: приложение, подтверждение на устройстве, ключ безопасности и другие способы.

Откройте настройки безопасности через официальный сайт или приложение:

1. Включите дополнительную защиту и прочитайте, как работает выбранный способ входа.
2. Проверьте доступные варианты восстановления.
3. Если сервис выдаёт резервные коды, сохраните их в защищённом месте так, чтобы они были доступны и при потере основного телефона. Никому их не сообщайте.

В Google резервный код можно использовать вместо обычного второго шага, когда тот недоступен. У другой почты порядок может отличаться; для рабочего аккаунта часть настроек определяет администратор.

Такая защита не делает аккаунт неуязвимым. Но вход только по паролю оставляет меньше барьеров. Включение защиты и подготовку восстановления лучше делать вместе.

Источники: [Google — двухэтапная аутентификация](https://support.google.com/accounts/answer/185839?hl=ru), [резервные коды](https://support.google.com/accounts/answer/1187538?hl=ru).
