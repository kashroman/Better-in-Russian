# Руководство по эффективной жизни

Практический справочник о том, как с минимальными затратами денег, времени и сил получить больше здоровья, безопасности, финансовой устойчивости и свободы.

Проект содержит сотни рекомендаций по:

- долголетию и профилактике болезней;
- безопасности и экстренным ситуациям;
- экономии и личным финансам;
- защите от мошенничества и юридическим рискам;
- работе, предпринимательству и навыкам;
- отношениям, семье и детям;
- путешествиям и личной безопасности.

Каждая рекомендация содержит:

- стоимость и затраты;
- ожидаемую пользу;
- уровень доказательности;
- ссылки на исследования и официальные источники.

## О проекте

Эта книга отвечает на практические вопросы, которые возникают у большинства людей:

| Вопрос | Раздел |
| --- | --- |
| Как снизить риск ранней смерти? | 1. Не умереть раньше времени |
| Как сохранить здоровье и энергию? | 2. Не разрушать себя |
| Как эффективнее использовать время? | 3. Управление энергией и вниманием |
| Как не потерять деньги? | 4. Финансовая безопасность |
| Какие ошибки стоят слишком дорого? | 5. Юридическая и бытовая безопасность |
| Какие навыки действительно окупаются? | 6. Обучение и развитие |

## Принцип проекта

Это не сборник советов из интернета. Цель проекта — собрать рекомендации с понятной ценностью:

**что нужно сделать → сколько это стоит → что это даёт → насколько этому можно доверять.**

## Перевод и адаптация

Русская версия адаптируется для русскоязычных читателей:

- китайские реалии заменяются на понятный российский контекст;
- юридические и бытовые вопросы рассматриваются с учётом российского законодательства;
- суммы и примеры адаптируются под местные условия;
- сохраняются ссылки на научные исследования и официальные источники.

## Структура

- `book/` — основные главы книги;
- `docs/` — расширенные материалы и исследования;
- `index.html` — веб-версия для поиска и навигации.

## Статус перевода

Проект находится в процессе русской локализации.
