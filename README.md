# Руководство по эффективной жизни

Практическая база знаний о здоровье, безопасности, времени, деньгах, работе и семье. Принцип: **что сделать → затраты → ожидаемый эффект → доказательства → источники и ограничения**.

Русская локализация форка [HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter). Рабочая ветка — `russian-localization`.

## Статус

В оригинале **31 глава и 498 отдельных рекомендаций**. На русский переведены **главы 1–12: 268 рекомендаций** с сохранением всех пунктов и DOI исходных глав. Это не число независимых научных фактов: отдельные записи пересекаются и используют одни исследования.

Полная локализация **ещё не завершена**. Главы 13–31, расширенные материалы и веб-интерфейс остаются в работе. В переведённых главах отмечены непроверенные библиографические сведения и вопросы российской адаптации. Наличие перевода не означает завершённого медицинского или юридического аудита.

## Как читать доказательства

- **A** — авторская категория для количественных данных крупных исследований, метаанализов и в ряде глав официальных документов. Это не единая клиническая шкала качества.
- **B** — ограниченная исследовательская база, отдельное исследование или трудный для количественной оценки эффект.
- **C** — практический опыт, рассуждение или консенсус без прямого измерения результата рекомендации.

Буквы сохранены для прослеживаемости оригинала. Они не равны GRADE, уровням рекомендаций USPSTF или гарантии пользы. Наблюдательная связь может объясняться исходным здоровьем, достатком и другими факторами. Проценты из разных пунктов нельзя складывать.

| Термин | Что означает |
| --- | --- |
| Общая смертность | Смерть от любой причины за период наблюдения |
| RR | Отношение рисков; 0,8 означает относительную разницу 20%, не 20 процентных пунктов |
| HR | Отношение интенсивностей наступления события во времени; не индивидуальная вероятность |
| OR | Отношение шансов; особенно при частом исходе отличается от отношения рисков |
| IRR / RaR | Отношение частот событий; важно, какие события и за какое время считали |
| 95% ДИ / CI | Доверительный интервал, показывающий статистическую неопределённость оценки |
| Байесовский интервал | Интервал правдоподобных значений при заданной модели и предпосылках |
| d / g | Стандартизованный размер эффекта; это не проценты улучшения |
| r | Коэффициент корреляции; сам по себе не доказывает причинность |
| P | Статистический показатель совместимости данных с нулевой гипотезой, не вероятность истинности вывода |
| I² | Показатель неоднородности результатов исследований в метаанализе |
| РКИ / RCT | Исследование со случайным распределением по группам |
| Когортное исследование | Наблюдение за группой людей во времени |
| Метаанализ | Статистическое объединение исследований с учётом их различий |
| GRADE | Система оценки определённости доказательств, отдельная от авторских A/B/C |
| Обратная причинность | Например, болезнь уменьшает активность, а не только наоборот |
| Абсолютный риск | Частота события: снижение с 10% до 8% — два процентных пункта, хотя относительное снижение 20% |
| DALY | Потерянные годы здоровой жизни из-за преждевременной смерти и ограничений здоровья |
| MET·ч | Объём активности с учётом интенсивности и времени |
| ИМТ / BMI | Масса в килограммах, делённая на квадрат роста в метрах; не исчерпывающая оценка здоровья |
| LDL / ЛПНП | Липопротеины низкой плотности, один из показателей липидного обмена |
| PHQ-9 | Опросник депрессивных симптомов, который не заменяет диагноз |

- `book/` — главы; китайские версии намеренно сохранены для сравнения.
- `docs/` — расширенные материалы и исходные записи проверок; их перевод следует после глав.
- [Правила русской локализации](docs/РУССКАЯ_ЛОКАЛИЗАЦИЯ.md).

`index.html` пока использует китайский интерфейс и исходный формат данных; русское содержание выше — рабочая навигация этого этапа. Прежнее изображение обложки также ещё не локализовано и убрано из русской первой страницы до обновления.

Проектирование Telegram отложено до полного перевода и аудита базы. Предварительный документ сохранён как исторический черновик, не как действующая структура рубрик. «Скучная База» — одна из возможных будущих рубрик.
